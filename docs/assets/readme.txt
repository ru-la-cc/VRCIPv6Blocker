================================================================================
VRCIPv6Blocker
================================================================================

【概要】
VRChatの起動時にIPv6を一時的にブロックし、VRChat終了時に自動的に設定を
復元するWindows用ランチャーアプリケーションです。
VRChat内で動画プレイヤーが読み込まれないエラーの回避策のひとつとして作成しています。

【主な機能】
・IPv6ブロック機能（ファイアウォールブロックルール追加またはネットワークアダプタのIPv6無効化のどちらかを選択可能）
・VRChat終了時の自動設定復元
・ショートカット作成機能

【システム要件】
・OS: Windows 10/11（動作確認済み: Windows 11のみ）
・管理者権限が必要

【インストール方法】
1. 任意のフォルダ（例：C:\Tools\VRCIPv6Blocker）にファイルを配置
2. VRCIPv6Blocker.exe を右クリック → 「管理者として実行」
3. VRChat.exeのパスまたは起動用ショートカットを必ず設定してください
   （このパスのプログラムまたはショートカットで起動するため）
4. 基本的に以下の設定にすることを推奨します：
   ・アプリ起動時にVRChatを自動起動: オン
   ・VRChat終了時にこのアプリも終了: オン
   ・起動時にこのアプリのウィンドウを最小化する: お好みで
   ・ファイアウォールでブロックする: オン
5. 「ショートカット作成」ボタンでランチャー用ショートカットを作成

【使用方法】
■作成したショートカットからの起動
作成したショートカットからVRChatを起動してください。
IPv6が自動的にブロックされ、VRChat終了時に設定が復元されます。

※注意: 事前にVRCIPv6Blocker.exeを終了しておいてください。
　　　　2重起動防止のため、別で起動中だと起動できません。

■通常起動
設定変更やブロック状態の手動解除を行う場合は、
VRCIPv6Blocker.exe を直接実行してください。

【トラブルシューティング】
■アプリが異常終了してIPv6ブロック状態が残っている場合
1. アプリから解除:
   ・ファイアウォール方式: 「FWブロック解除」ボタン
   ・ネットワークアダプタ方式: 「IPv6有効化」ボタン
2. 手動解除:
   ・ファイアウォール方式: Windows Defenderファイアウォール設定から
     送信の規則「{31952356-61C8-42F9-9D19-AC73E9AF5ED5}_VRCIPv6Blocker」を削除
   ・アダプタ無効化方式: ネットワーク設定からIPv6を有効化

【アンインストール方法】
1. タスクスケジューラで作成された起動用タスク
   「{31952356-61C8-42F9-9D19-AC73E9AF5ED5}_VRCIPv6Blocker」を削除
2. 作成したショートカットを削除
3. インストールフォルダを削除

※IPv6ブロック状態が残っている場合は、事前に解除するか、
　後で自分でファイアウォールやネットワークアダプタの設定を開いて
　解除・有効化してください。

【注意事項】
・このツールは管理者権限が必要です
・VRChat公式のサポート対象外のツールです
・ベータ版のため、予期しない動作が発生する可能性があります
